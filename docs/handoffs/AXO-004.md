## Outcome and scope

The operator rejected the earlier fits and requested a new system around the actual AXO Pet, 2:3 framing, head patterns, backgrounds, better hand tools, and lineage eyes/skin markings. `/gear-studio` now serves the anatomy atelier. The previous 30-design collection stays at `/gear-concepts` with its rejected-fit status explicit.

The candidate wardrobe now has nine designs: Liquidity Crown, Signal Runner Headband, a replacement Degen Node Cap, three clothes designs and three freshly generated tools. The operator rejected the previous cap and the isolated rings’ high-angle perspective. That cap source remains archived. The replacement cap and both other headpieces are drawn on the reference head camera before registration. One item occupies each preview slot, so an outfit contains five pieces. The rig has 57 anchors, explicit clothing UV surfaces, separate feet, a projective four-corner palm socket and matching-base fingers above tools. The canonical Pet remains at 1:1 in a 1024×1536 portrait. Cap, crown and hood guides map the skull, temples, neck and gill openings. All three use a rigid proportional fit of accessory-only source pixels. Hidden rear material is fully occluded by the skull and excluded; matching-base gills draw above the visible fabric. Complete NFT art uses independent whole-object images. Generated Pet anatomy is excluded from every wearable texture. Hood artwork remains future work.

Six complete lineage base paintings have their own integrated eye colors and organic skin pigmentation. They are registered and baked to one exact silhouette, with matching foreground anatomy. Runtime uses one full base, never an eye/marking overlay. The earlier overlay proposal was rejected by the operator and removed. Three independent scenes support Pet and full-size Gear portraits: Degen Den, Tech Hatchery, Arcane Workshop. Transparent wearables do not contain scenes. Bazaar examples use this same source renderer.

The grip plane now leans 18° toward the fingers. All three upright tools now default to the operator’s X −14, Y 2, scale 120%, rotation 11°. These replace the earlier banana-only X −5, Y −4, 118%, 11° values. Per-piece X/Y, scale and rotation controls edit the worn piece; edits replace defaults rather than stacking them. Only the upper thumb draws above tool handles; the rounded thumb ball stays behind. Frame clipping replaces the old out-of-bounds rejection that froze position updates at larger tool fits. Browser verification includes the operator’s 118% / 9° tool settings with independent X and Y changes.

Read [ANATOMY_ATELIER.md](../ANATOMY_ATELIER.md) for geometry, authoring inputs, controls, rebuilding and integration. Review artifacts and generation prompts live under `docs/reviews/`. The operator also has the original PNG authoring inputs and full review bundle in `gear-fit-foundation`.
